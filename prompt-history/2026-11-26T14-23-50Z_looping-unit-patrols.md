# Looping unit patrols

UTC: 2026-11-26T14-23-50Z
Harness: Codex
Model: GPT-6; exact version, reasoning setting, token counts and elapsed task time are not exposed by the harness.

Add patrolling to the circle menu for all units. It works exactly like the path planning mode but when last step is reached it will stat over again from the beginning and loop. If only one path step is defined it will loop between current position and that one step (so a step will be inserted automatically at current position). Ensue units in patrol mode attack all enemy units automatically. Integrate patrols into cfbl. Patrols can be unlocked for 2 stars in unit automation perk (this will also enable the option in circle menu). It will be disabled until but when user clicks the disabled version it will open and focus the perk in the menu (if command center is available). Also multiple units can patrol on the same route when selected together and they will start at different points in time to evenly distribute along the patrol route unless they are assigned to a formation group, they they will move in formation together.
