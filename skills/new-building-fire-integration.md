# Building integration lessons: fire department

A support building requires more than buildingData: add explicit prerequisite checks, event-driven unlocks, sidebar card and image mapping, AI/API tech tree, production/spawn service capacity, owner checks, destruction/reassignment, save and host synchronization. Define smoke spots explicitly in source-image pixels. The fire department smokes from the hose-tower mast at `{ x: 228, y: 52 }` on the 384px map art; those pixels scale with the 3×3 footprint. Add new-building assets to prepared tiers before play. Service discovery must use reusable indexes, not building scans inside every unit tick. Supply bays and truck ownership are separate from factory spawn routing; land vehicles always leave the Vehicle Factory. Do not import `sound.js` from a simulation or audio helper that unit tests mock; load playback on demand. Visual effects must use `Math.random()`, and repair timestamps must use simulation time. Review these checklist entries after player feedback rather than assuming visual and usability acceptance.
