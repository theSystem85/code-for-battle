# C-5 parachute visual provenance

Patrick authorized Codex to create the canopy on 2026-11-22. ImageGen produced the transparent, off-white ripstop dome. The source was cropped to its alpha bounds and converted to a 192×99 WebP at quality 85.

- Source art: `public/images/effects/c5_parachute_canopy.webp`
- Prepared sprite: `effect:c5:parachute`, 18 logical pixels wide at 1×, 2×, and 3× density
- In-game rendering: four canopies per descending vehicle, with four dynamic suspension lines per canopy
