# Vehicle and unit weights

Weights are metric tonnes and are gameplay inputs for the C-5's 122 t payload. Ground vehicles are airliftable; aircraft and ships are not.

| Unit | Weight (t) |
|---|---:|
| Tank V1 / V2 / V3 | 42 / 60 / 73 |
| Light / Rocket tank | 20 / 25 |
| Howitzer | 32 |
| Recovery tank | 64 |
| Harvester | 35 |
| Fire engine / Ambulance | 20 / 4 |
| Tanker / Ammunition truck | 28 / 30 |
| Mine layer / sweeper | 28 / 53 |
