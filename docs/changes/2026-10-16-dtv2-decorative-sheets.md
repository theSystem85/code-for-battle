- [x] **Feature: Decorative tile sheets v2 (dtv2)**
  Replaced the rejected `dt_*_1024_q85` sheets with five `dtv2_<biome>` sheets (grass, soil, sand, snow, universal) packed through the Sprite Sheet Editor from top-down Codex source images. Sprites are sized to scale (1 tile ~ 10 m: vehicles, trees and small props 1x1, groves/ruins/barns 2x2, lakes/villages 3x3). Tiles use only `[biome|universal, decorative, passable|impassable]` plus `group_N` for multi-tile sprites. Old `dt_*` paths are listed as retired so stored settings fall back. Removed the v1 packer script. Version 0.62.0 after the 2026-10-17 rebase onto main 0.60.0 (originally 0.56.0).
