# Unit automations, first slice

- [x] **Programmable unit automations (units only)**: Players build small `if` / `while` state-machine automations (max 7 states), enable global ones, apply per-unit ones from a radial menu, and get a conflict message with "pause until the order is done" when a `while` automation is overridden by a new direct order. Buildings, grants and folders, enemy AI migration and LLM-written automations are later work. Spec: [Unit automation — first slice](../../specs/unit-automation-first-slice.md)
