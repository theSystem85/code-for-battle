- [x] **Bug: old stored sprite sheet settings hid the new default sheets**
  Players who had used custom sprite sheets before saw only debris_craters_tracks in Map Settings and on the map, and the sprite sheet editor could list only debris. The selection was stored as a whitelist, so new default sheets were never added, and retired sheets dropped out of it. The service worker also served index.json from a cache-first cache, so an old deploy's sheet list could stay in use.
  Fix: the bundled sheet registry decides which sheets are available, and index.json can only add sheets to it. Map Settings and the editor always list every default sheet plus debris and user-added sheets. The selection is now stored as explicit opt-outs (`rts-integrated-spritesheet-disabled-sheets`), so new default sheets are enabled automatically. The legacy whitelist (`rts-integrated-spritesheet-selected-sheets`) is migrated once to "nothing disabled" and then removed. Retired sheets in stored data are ignored. Sprite sheet JSON and images under /images/map/sprite_sheets/ are now fetched network-first, falling back to the cache when offline.
