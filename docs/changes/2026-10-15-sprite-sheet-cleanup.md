- [ ] **Cleanup: sprite sheets, water bitmaps and build-only terrain sources; multi-tile decorations placed first (PR #688)**
  Plain ground now always comes from the default organic terrain; custom sprite sheets only add decorations on top.
  - Removed sheets: `seasons_1024_q90_2`, `seasons_1024_q90_3`, `rocks_64x64_1024x1024_q85` (no tag file) and `rockCliffsMountains_64x64_1024x1024` (about 1.0 MB). Kept: streets, crystals, combat decals, explosion animation and the five `dt_*` sheets.
  - `src/ui/spriteSheetRegistry.js` is now the one sheet list for Map Settings and the Sprite Sheet Editor. The editor's six non-existent fallback files are gone and its preview background points at `images/terrain/source/meadow.webp` instead of the missing `images/map/land01.webp`.
  - Migration: the old `major_sprite_sheet_default` retirement now covers every removed sheet. Stored editor metadata, applied metadata, the last-opened sheet and the sheet selection that point at a retired sheet are removed or filtered on startup, and saved games that reference one load with the active sheet cleared.
  - Placement (`src/rendering/decorationLayout.js`): multi-tile sprites are placed first from the sheet JSON groups at hash-chosen anchor cells, only where every covered cell is free land of the same biome; then 1x1 sprites fill remaining cells at random. The old per-cell classification and the post-hoc matching-group search were removed. Deterministic per map, about 2 ms for an 80x80 map. On seed 23 / 80x80: 105-109 multi-tile sprites per map, including 3-11 lakes or frozen lakes, all of whose cells block movement.
  - Ground cut-out (`src/rendering/decorationCutout.js`) makes each sprite's painted ground transparent and feathers the edges, so decorations sit on the organic ground without square patches. Universal sprites that are mostly painted ground (clearing, rubble, path stones) are not placed.
  - Water: always procedural. Removed `water_spritesheet.webp`, `water01.webp`, `water_animation.gif`, the classic water fallback and the "procedural water" settings toggle.
  - Moved build-only terrain sources (about 3.2 MB) from `public/images/terrain/source/` to `assets-src/terrain/` and updated the three terrain build scripts. Removed `terrain/source/rocks.webp`, the dead `make:sprites` script and the committed Lighthouse reports (now ignored).
  - Fixed: a restored saved game with custom mode on no longer switches custom mode off when it carries no single active sheet.
  - Tests: `tests/unit/decorationLayout.test.js`, `tests/unit/spriteSheetRegistry.test.js`, updated `textureManagerIntegratedSheets`, `spriteSheetEditorMode` (now passes) and `proceduralWaterRendering` e2e.
