# Unit policies, first slice

- [x] **Programmable unit policies (units only)**: Players build small `if` / `while` state-machine policies (max 7 states), enable global ones, apply per-unit ones from a radial menu, and get a conflict message with "pause until the order is done" when a `while` policy is overridden by a new direct order. Buildings, grants and folders, enemy AI migration and LLM-written policies are later work. Spec: [Unit policies — first slice](../../specs/unit-policies-first-slice.md)
