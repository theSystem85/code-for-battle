- [ ] **Feature: Biome-aware decorative map tiles (PR #688, rebased onto main 0.53.0)**
  Five decorative-tile sheets (`dt_grass`, `dt_soil`, `dt_sand`, `dt_snow`, `dt_universal`, WebP q85, packed by `scripts/pack-biome-decorative-tiles.mjs`) are listed in `public/images/map/sprite_sheets/index.json` and the default Sprite Sheet Editor sheet list, so they take part in main's enabled-sheets flow like any other tagged sheet.
  - Land tiles pick decorations from the cell's own `tile.biome` (explicit `biomeTag` still wins), falling back to the Map Settings biome. Multi-tile groups only fit when every covered cell is land in the same biome, so lakes and forests never straddle a biome edge on mixed maps. `universal` props supplement any biome that has its own decorative art.
  - Integrated into main's cached land buckets: `buildIntegratedLandBuckets` now also builds a `universal` bucket and a precomputed `decorativeWithUniversal` list per biome, and filtered group candidates are cached in a `WeakMap` keyed by the catalog array (self-invalidating when sheets change), so per-tile lookups do not allocate.
  - Impassable decorative tiles (frozen lakes) block movement: `buildOccupancyMap` passes `mapGrid` and the tile biome to the tag lookup and now does one lookup per tile instead of two. Main had removed `isLandTileImpassable`; the PR's change to it was dropped.
  - New SSE tags: `universal`, `spring`, `summer`, `autumn`, `winter`.
  - Spec renumbered from 087 (taken by GPU chimney smoke on main) to `specs/120-map-decorative-tiles-research.md`. Version 0.54.0.
  - Tests: biome/universal group picking, cross-biome group rejection, implicit `tile.biome` selection and frozen-lake occupancy blocking in `tests/unit/textureManagerIntegratedSheets.test.js`.
  Visual check: Playwright headless Chromium, seed 23, grass / mixed / snow maps at DPR 1 and 3 (`/workspace/biome-shots/`). Known limitation: decorative cells are chosen per cell by hash, so neighbouring cells are rarely all decorative and in practice only the 1x1 DT pieces appear; the large multi-tile pieces (lakes, forests, frozen lakes) need anchor-based placement to show up on generated maps.
