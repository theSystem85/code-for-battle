# PR #688 round 4 (2026-10-18, 0.61.0)

- **Removed `streets24_q90_1024x1024` and `rockCliffsMountains_64x64_1024x1024`.** Images and JSON are deleted, both paths left `DEFAULT_SSE_SHEETS` and `index.json`, and the texture manager no longer preloads a default street atlas. Streets and rock cliffs render from the organic terrain art (`drawRoad`, cliff art); custom sheets with `street` tiles still work. Both paths are listed in `RETIRED_SPRITE_SHEET_PATHS`, so stored settings, editor state and saves that still name them fall back cleanly instead of fetching missing files.
