# Second background music track and random playlist

- [x] **Second background music track with random playlist**: added `public/sound/music/music02.mp3` (original instrumental, generated with ElevenLabs Music v2.5, 2:11, 192 kbps / 48 kHz, loudness-matched to `music01.mp3` at about -12 LUFS). Background music no longer loops a single file: when a track ends, the next one is picked at random without repeating the same track twice in a row, and every track's Audio element is loaded once and cached (the next track is preloaded while the current one plays). Toggle, pause/resume, `terminateAllSounds`, master volume and the headless automation mute keep working. Track choice uses `Math.random` instead of `gameRandom`, so local music never advances the lockstep PRNG. The offline asset manifest picks up the new MP3 automatically (all `.mp3` files under `public/` are bulk assets). Spec: none
